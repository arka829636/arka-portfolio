🚀 Run the Project Locally

1. Clone the repository

git clone https://github.com/arka829636/arka-portfolio.git

2. Open the project

cd arka-portfolio

3. Install dependencies

npm install

4. Start the development server

npm run dev

If PowerShell blocks npm, use:

npm.cmd run dev

Vite will provide a local development URL, normally similar to:

http://localhost:5173/

📱 Test on Mobile

To test the local website on a phone:

npm run dev -- --host

Connect the phone and computer to the same Wi-Fi network and open the Network URL shown by Vite on the phone.

The deployed Vercel website can also be opened directly from any mobile browser.

📦 Build for Production

Create a production build:

npm run build

Preview the production build locally:

npm run preview

🔄 Update GitHub

After making changes:

git status
git add .
git commit -m "Update portfolio"
git push origin main

If the repository is connected to Vercel, pushing to main can trigger a new deployment automatically.
